Leonida Trophy Guide — an offline web app that guides and tracks all 55 PlayStation 5 trophies of Grand Theft Auto VI: the official list with saved progress, filters and a spoiler setting, a roadmap to the platinum, the one missable trophy flagged, and a cited guide for each trophy. It works from its own files with the network off.

## Run it

```sh
node serve.ts
# open http://localhost:8080
```
